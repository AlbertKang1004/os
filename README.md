# OS Development
This repository contains the source code for a simple operating system kernel written in C and NASM. The kernel is designed to run on x86_64 architecture and provides basic functionality such as memory management, task scheduling, and hardware interaction.

---

## Features
- Printing to the screen (Added 2026-05-19)
- Global Descriptor Table (Added 2026-05-21)
- Interrupt Handling / Interrupt Descriptor Table (Added 2026-05-22)
- PIC Initialization (Added 2026-05-22)
